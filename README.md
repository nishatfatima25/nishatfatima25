## 🚀 a few builds I’m proud of

### 🪄 [InterviewMatrix — AI Job Companion](https://github.com/nishatfatima25/InterviewMatrix-AI-Job-Companion)

An AI-powered job-prep platform that creates **customized resumes, interview questions and feedback** from a user’s skills and job description.

`React.js` `Node.js` `Express.js` `MongoDB` `Gemini AI` `REST APIs`

### ♻️ WasteWise

A role-based waste-management experience for **citizens, collectors and admins**, with pickup/report flows, maps and data visualizations.

`JavaScript` `Leaflet.js` `OpenStreetMap` `Chart.js` `LocalStorage`

[![Live Demo](https://img.shields.io/badge/Open%20Live%20Demo-7F00FF?style=flat-square\&logo=netlify\&logoColor=white)](https://wastewiiise.netlify.app/)

### 🛒 [Supermarket Billing System](https://github.com/nishatfatima25/Supermarket-Billing-System)

A C++ billing + inventory system built around **OOP and persistent file handling** — simple idea, solid fundamentals.

`C++` `OOP` `File Handling`
